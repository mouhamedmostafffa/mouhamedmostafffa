## 🧠 About Me

<img align="right" width="380" src="https://user-images.githubusercontent.com/74038190/212284158-e840e285-664b-44d7-b79b-e264b5e54825.gif">

I'm **TOJI**, a Full Stack and Backend-focused developer from **Egypt 🇪🇬**, currently building my craft as a student developer with a strong pull toward **AI engineering**, **clean architecture**, and **systems that scale**.

I care about the parts of software most people skip past — how a backend is structured, how state flows through an app, why one query is fast and another isn't. My work sits at the intersection of **full stack development** and **applied AI**: building interfaces that feel considered, and the APIs and services behind them that actually hold up.

Right now, that means:

- 🛠️ Designing and shipping **full stack products** end-to-end — frontend, backend, and the infrastructure that connects them
- ⚙️ Writing **backend systems** with an emphasis on clean architecture, maintainability, and performance
- 🤖 Exploring **AI engineering** — prompt design, LLM-powered features, and API-driven automation
- 📚 Studying software engineering fundamentals deeply, not just frameworks — data structures, system design, and design patterns
- 🌱 Contributing to and learning from the **open source** community

I'm not chasing buzzwords. I'm chasing systems that work well, code that reads clearly, and products that solve something real.
